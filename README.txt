Instructions

1. This folder contains a complete personal website that runs locally.
2. Open index.html to preview the site on your computer.
3. To deploy on GitHub Pages or any static hosting service, upload the full folder.

Replace publication images

1. Open the assets folder, then open the papers folder.
2. Replace placeholder images with your own figures.
3. Keep the filenames unchanged so the page updates automatically.

Add paper PDFs for the Download PDF buttons

1. Create or open the assets pdfs folder.
2. Put your paper PDFs there.
3. Keep the filenames unchanged to match the buttons on each publication card.

Edit content and styling

1. Edit text in index.html.
2. Edit styles.css for colors and layout.
3. Edit script.js for filtering logic and animations.
